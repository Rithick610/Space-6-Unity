# Space 6 – Unity Game

Space 6 is a 2D Unity game featuring 6 levels, developed as a personal project to learn Unity game development and C# scripting.

## Features
- 6 playable levels
- Player movement and controls
- Enemy mechanics and collisions
- Basic UI and game flow
- Gameplay logic implemented using C#

## Tech Stack
- Unity
- C#
- GitHub (via GitHub Desktop)
